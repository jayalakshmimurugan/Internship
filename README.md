# Student & Department JPA Management REST Service

A production-grade Spring Boot microservice backed by **Spring Data JPA** and a relational database engine. Features bidirectional entity relationships (`@OneToMany` / `@ManyToOne`), automated DDL schema management, Jakarta Bean Validation, and a clean separation of concerns where controllers only handle HTTP transport concerns.

---

## 📋 Core Requirements Covered

- [x] **Two Entities with a Mapped Relationship**:
  - `Department` (Parent Entity) with `@OneToMany(mappedBy = "department")`
  - `Student` (Child Entity) with `@ManyToOne` and `@JoinColumn(name = "department_id")`
- [x] **Repository Interfaces**:
  - `DepartmentRepository extends JpaRepository<Department, Long>`
  - `StudentRepo extends JpaRepository<Student, Long>`
- [x] **Schema Managed by DDL Config**:
  - Configured via `spring.jpa.hibernate.ddl-auto=update` to automatically create and update relational tables, primary keys, foreign key constraints, and unique indexes.
- [x] **API Backed by a Real Relational Database**:
  - Embedded H2 relational database engine with full SQL transaction support, ACID compliance, and H2 Web Console.
- [x] **Strict DTO Isolation & Bean Validation**:
  - Controllers return `StudentResponseDto` and `DepartmentResponseDto`, never leaking JPA entities.
  - Incoming requests are validated via `@Valid` with Jakarta annotations.
- [x] **Centralized JSON Error Handling**:
  - `@RestControllerAdvice` translates validation and runtime exceptions into `ErrorResponseDto`.
- [x] **Runs with a Single Command**:
  - Packaged with Maven Wrapper (`mvnw` / `mvnw.cmd`). Runs immediately on any machine with zero external database installation.

## 🏛️ Entity Relationship Architecture

```
   ┌───────────────────────────┐                ┌───────────────────────────┐
   │        Department         │ 1            * │          Student          │
   ├───────────────────────────┤────────────────├───────────────────────────┤
   │ Long id [PK]              │                │ Long id [PK]              │
   │ String name [UNIQUE]      │◄───────────────┤ Long department_id [FK]   │
   │ String code [UNIQUE]      │  @ManyToOne    │ String name               │
   │ List<Student> students    │  @OneToMany    │ int age                   │
   │                           │                │ String email [UNIQUE]     │
   │                           │                │ LocalDateTime createdAt   │
   └───────────────────────────┘                └───────────────────────────┘
```

### Hibernate DDL Generated Schema
```sql
CREATE TABLE departments (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(100) NOT NULL UNIQUE,
    code VARCHAR(20) NOT NULL UNIQUE
);

CREATE TABLE students (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    age INTEGER NOT NULL,
    email VARCHAR(150) NOT NULL UNIQUE,
    department_id BIGINT NOT NULL,
    created_at TIMESTAMP NOT NULL,
    CONSTRAINT FK_students_departments FOREIGN KEY (department_id) REFERENCES departments(id)
);
```

## 🚀 How to Run with a Single Command

### Prerequisites
- **Java 21** or later (`java -version`)

### Run the Application

#### Windows (PowerShell / Command Prompt):
```cmd
.\mvnw.cmd spring-boot:run
```

#### Linux / macOS:
```bash
./mvnw spring-boot:run
```

The application will start on **port 8081**:
- REST API: `http://localhost:8081`
- H2 Database Console: `http://localhost:8081/h2-console` *(JDBC URL: `jdbc:h2:mem:college`, User: `sa`, Password: empty)*

## 📡 API Endpoints Documentation

All endpoints consume and produce `application/json`.

| HTTP Method | Endpoint | Description | Status Code |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/v1/health` | Health check & endpoint directory | `200 OK` |
| `GET` | `/api/v1/departments` | Retrieve all departments with student counts | `200 OK` |
| `POST` | `/api/v1/departments` | Create a new department | `201 Created` / `400 Bad Request` |
| `GET` | `/api/v1/students` | Retrieve all students linked to departments | `200 OK` |
| `GET` | `/api/v1/students/{id}` | Retrieve student by ID | `200 OK` / `404 Not Found` |
| `POST` | `/api/v1/students` | Create student and link with Department | `201 Created` / `400 Bad Request` |
| `PUT` | `/api/v1/students/{id}` | Update student details or change department | `200 OK` / `400 Bad Request` / `404` |
| `DELETE` | `/api/v1/students/{id}` | Delete student by ID | `200 OK` / `404 Not Found` |

## 🛠️ Testing with PowerShell

```powershell
# Health check
Invoke-RestMethod -Uri "http://localhost:8081/api/v1/health"

# Get departments
Invoke-RestMethod -Uri "http://localhost:8081/api/v1/departments"

# Get all students
Invoke-RestMethod -Uri "http://localhost:8081/api/v1/students"

# Create a new student
$body = @{
    name = "Alex Turner"
    age = 23
    email = "alex.turner@example.com"
    department = "CS"
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://localhost:8081/api/v1/students" -Method Post -Body $body -ContentType "application/json"
```
